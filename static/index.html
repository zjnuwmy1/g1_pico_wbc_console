🔧 根治：启用 PC2 手服务端自启（一次性，需 PC2 sudo）

        
手服务端在 PC2 一重启/掉网就死。启用 systemd 后开机自起 + 崩了 10s 自愈，从此不用手动重启。
          GUI 无法替你输 sudo 密码，复制到终端跑一次即可：

        
ssh -t g1pc2 'sudo systemctl enable --now brainco-hand-server.service && systemctl status brainco-hand-server.service --no-pager'

        
        
启用后改用 sudo systemctl restart brainco-hand-server 重启，别再点「重启手服务端」按钮（会和 systemd 抢）。
