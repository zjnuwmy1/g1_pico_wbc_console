手柄操作速查

        

          

            
启动流程

            
    
              
  1. 摆校准姿势：站直、双脚并拢、大臂自然下垂、小臂前屈 90°（L 形）、掌心相对
    2. 
              
  2. A+B+X+Y 同按 → 启动策略 + 全身校准（机器人开始自平衡）
    3. 
              
  3. 先把手臂对齐机器人当前姿态，再 A+X → 进入全身跟随 (POSE)
    4. 
            

            
急停

            
    
              
  • 手柄：A+B+X+Y
    • 
              
  • 本页：底部红色急停按钮（向部署进程发官方急停字符 o）
    • 
            

          

          

            
模式切换

            

              
A+X行走规划 (PLANNER) ↔ 全身跟随 (POSE)

              
B+Y全身跟随 (POSE) ↔ 上身冻结+行走 (FROZEN_UPPER)

              
左摇杆按下进/出三点跟随 (VR_3PT)（头+双手控上半身，先对齐手臂！）

              
A+B / X+Y下/上一个步态（走/跑/蹲/跪/爬/拳击/跳…）

              
左摇杆移动方向

              
右摇杆横向转向

              
扳机对应手抓握

            

          

        

        
⚠ 切入全身跟随 (POSE) / 三点跟随 (VR_3PT) 前必须先让身体对齐机器人当前姿态，否则机器人会瞬间猛动！
